# Finger Prosthetic — Cybathlon University Project

Designing slim, functional finger prosthetics for myoelectric arm prostheses — built for the Cybathlon challenge.

---

## The Problem

Current finger prosthetics for myoelectric arms are **too bulky**. The wiring runs on the outside of the fingers, adding unnecessary size and making the prosthetic less practical and less natural-looking.

## My Solution

This design routes the wiring **through the inside of the finger**, resulting in:
- A significantly slimmer profile
- A cleaner, more natural appearance
- Better fit within a prosthetic hand shell
- Improved comfort and usability for the wearer

## Context

This project was developed as part of a **university assignment** centered around the **Cybathlon** — an international competition where people with physical disabilities use advanced assistive technologies to complete everyday tasks.

The goal was to improve upon existing prosthetic finger designs to make them more practical for real-world use.
